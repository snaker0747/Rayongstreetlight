# 🏮 ระบบแดชบอร์ดติดตามงานสำรวจโคมไฟสาธารณะ เทศบาลนครระยอง

ระบบแดชบอร์ดแสดงผลสถิติและสถานะการสำรวจโคมไฟสาธารณะในเขตเทศบาลนครระยองแบบ Real-time พร้อมแผนที่พิกัด GPS, การคัดกรองข้อมูลละเอียด, ระบบค้นหาซอย/ถนน และประวัติการบันทึกภาพถ่าย

🌐 **เข้าชมเว็บไซต์แดชบอร์ด:** [https://rayongcitystreetlight.vercel.app](https://rayongcitystreetlight.vercel.app)

---

## 🏗️ สถาปัตยกรรมระบบ (System Architecture)

```
[ เจ้าหน้าที่สำรวจภาคสนาม ]
         │ (บันทึกจุด / พิกัด GPS / ภาพถ่าย)
         ▼
[ Google AppSheet Application ]
         │ (Sync อัตโนมัติแบบ Real-time)
         ▼
[ Google Sheets Database (6,440+ จุด) ]
         │ (ดึงข้อมูลผ่าน GViz JSONP / Web API)
         ▼
[ Vercel Global Edge Network ]
         │ (Deploy อัตโนมัติจาก GitHub)
         ▼
[ เว็บแดชบอร์ดเทศบาลนครระยอง ]
```

---

## ✨ คุณสมบัติเด่นของระบบ

1. **สถิติภาพรวม Real-time:**
   - ยอดสำรวจสะสมทั้งหมด (6,440+ จุด)
   - สถิติสำรวจวันนี้ และยอดเปรียบเทียบกับเมื่อวาน
   - จำนวนผู้สำรวจทั้งหมด และค่าเฉลี่ยจุดสำรวจต่อวัน
   - สถิติตู้ควบคุมแยกต่างหาก

2. **การแสดงผลกราฟวิเคราะห์ขั้นสูง:**
   - กราฟแท่งแสดงปริมาณการสำรวจรายวัน (10 วันล่าสุด)
   - กราฟวงแหวน (Donut Chart) สัดส่วนชนิดโคมไฟ (ฟลูออเรสเซนต์, LED, แสงจันทร์/โซเดียม ฯลฯ)
   - กราฟแท่งซ้อน (Stacked Bar Chart) แสดงชนิดโคมไฟแยกตามชุมชน 29 ชุมชน

3. **ระบบค้นหาและตัวกรองอัจฉริยะ (Advanced Filter & Search):**
   - ค้นหาด้วยคำสำคัญ (Keyword Search)
   - กรองตามชุมชน (29 ชุมชน)
   - กรองตามชนิดโคมไฟ
   - กรองตามรายชื่อผู้สำรวจ
   - ค้นหาซอย / ถนน เชื่อมโยงตามชุมชนที่เลือก
   - เคลียร์ค่าคืนสู่หน้าเดิมโดยกราฟและสถิติไม่สูญหาย

4. **ตารางข้อมูลรายละเอียดและส่งออกข้อมูล:**
   - หน้าต่างแสดงตารางข้อมูลแบบแบ่งหน้า (Pagination)
   - เปิดดูภาพถ่ายจริงจากสถานที่
   - เปิดพิกัดไปยัง Google Maps ทันที
   - ส่งออกข้อมูลที่ผ่านการกรองเป็นไฟล์ **CSV (Excel UTF-8)**

## 📂 โครงสร้างไฟล์ในโครงการ

* `index.html` — หน้าเว็บแดชบอร์ดหลัก (HTML + CSS + JavaScript Vanilla + Chart.js)
* `logo.png` — ตราสัญลักษณ์เทศบาลนครระยอง
* `Code.gs` — ซอร์สโค้ด Google Apps Script (สำหรับ API สำรอง)
* `vercel.json` — ไฟล์กำหนดค่าการโฮสต์บน Vercel (Routing & Security Headers)
* `.gitignore` — รายการไฟล์ที่ยกเว้นการอัปโหลดขึ้น Git

## 🚀 การ Deploy บน Vercel

1. นำเข้า Repository นี้ (`snaker0747/Rayongstreetlight`) ไปยัง [Vercel](https://vercel.com)
2. ตั้งชื่อโปรเจกต์เป็น `rayongcitystreetlight`
3. กด **Deploy** จะได้โดเมน `rayongcitystreetlight.vercel.app` ทันที
4. ทุกครั้งที่มีการแก้ไขโค้ดและ `git push` เข้า branch `main` ระบบ Vercel จะอัปเดตหน้าเว็บจริงให้อัตโนมัติ (Automated CI/CD)
